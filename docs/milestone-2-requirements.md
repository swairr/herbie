# 里程碑二 需求方案

目标：记录每天把时间花在哪 —— 自动采集前台程序/窗口的活动片段，支持事后备注与归因到 Todo，日视图回顾，手动导出 markdown。

平台：暂时只支持 Windows。领域术语见根目录 `CONTEXT.md`；架构决策见 `docs/adr/`。

## 1. 活动片段采集（事件驱动，见 ADR 0002）

- 自写 N-API 原生模块注册 `SetWinEventHook`，监听两类事件：
  - 前台窗口切换（`EVENT_SYSTEM_FOREGROUND`）
  - 前台窗口标题变化（`EVENT_OBJECT_NAMECHANGE`，过滤到当前前台 hwnd）
- 事件发生时：关闭当前活动片段（写 `endAt`），开启新片段。
- 片段字段：`startAt`、`endAt`、`processName`（exe 文件名）、`title`（窗口标题快照，不可变）、`note`（备注，可编辑）、`todoId`（关联 Todo，0..1）。
- 所有片段全部保留，包括 1~2 秒的 alt-tab 碎片；里程碑二不做任何折叠/过滤。
- 仅应用运行期间记录；不补录应用未运行的时段。数据无限期保留。

### 空闲（Idle）

- 低频轮询（15~30 秒）`powerMonitor.getSystemIdleTime` 判定空闲，阈值默认 5 分钟、可在设置中修改。
- 空闲超过阈值：当前片段在**最后一次输入时刻**关闭；从该时刻到下一次输入为止记为一条 **Idle Segment（空闲片段）**。
- 空闲片段与其他片段同等对待：可编辑备注、关联 Todo（典型场景：补记"开会"）。
- 锁屏 / 睡眠（powerMonitor 的 lock / suspend 事件）：立即关闭当前片段。

### 下班（Off Work）

- 手动进入的暂停记录状态，入口：**主界面按钮 + 托盘菜单**。
- 下班期间不产生任何片段（包括空闲片段）。
- 下一次键鼠输入**自动结束**下班、恢复记录。

## 2. 日视图（"时间"页签）

- 主界面新增"时间"页签，与待办列表并列，默认显示今天，可切换日期查看历史。
- 顶部**聚合摘要**：
  - 按 `processName` 的时长排行
  - 按关联 Todo 的时长排行（"某 Todo 花费时长" = 其关联片段时长之和）
- 下方**片段列表**：按时间顺序，每行显示时间段 + 进程 / 标题 / 备注。
- 点击片段弹出编辑：填备注 + 搜索选择关联 Todo（按 title 搜索）。
- 展示与导出时，`note` 优先于 `processName` / `title` 显示；原始采集值保留不改。

## 3. Markdown 导出（手动）

- 触发：手动一键"导出时间记录"，**全量幂等重写**（同名文件覆盖），与里程碑一一致——无自动导出。
- 目录：复用里程碑一配置的导出目录，新增 `time/` 子目录，每天一个文件 `time/YYYY-MM-DD.md`。
- 文件内容：
  - 当日聚合摘要：按进程的时长表 + 按关联 Todo 的时长表
  - 按时间顺序的片段清单：时间段、进程、标题、备注、关联 Todo
- 按本地时区自然日（0 点）切分；跨午夜的片段在 0 点切开为两条。

## 里程碑二明确不做

- 隐私控制（无排除进程清单、无标题过滤/打码；标题原样落库并可能进入 git 仓库）
- 片段边界调整、拆分 / 合并（完整时间线编辑器）
- 甘特式可视化时间条
- 短片段的展示层折叠（原始数据全部保留，后续需要再加）
- 非 Windows 平台
- 相似待办查找、任务依赖、子任务拆解（里程碑三）
- 计划时间、日历视图、番茄钟、报表、外部日历同步（里程碑四）
