# 里程碑四 需求方案

目标：日程安排 —— 把待办安排到某一天，并可进一步安排一个时间段，通过「日程」页签规划每天的任务。

平台：Windows 与 Linux（本里程碑功能平台无关；不依赖追踪能力）。

领域术语见根目录 `GLOSSARY.md`；存储形态决策见 `docs/adr/0005-planned-slot-wall-clock.md`。

## 1. Planned Slot（计划时段）

待办上的单次日程安排，字段直接挂在 `todos`：

- `plannedDate` — 本地自然日 `YYYY-MM-DD`，`null` 表示未安排。
- `plannedStart` — 当日开始时刻 `HH:MM`（本地墙钟），`null` 表示当日不排具体时段。
- `plannedEnd` — 当日结束时刻 `HH:MM`（本地墙钟）。

规则：

- 一个 Todo 最多一个计划时段（不做多段、重复日程）。
- 有 `plannedDate` 才允许有时间段；时间段必须 `start`、`end` 同时存在，且 `start < end`，不跨天。
- 只有日期没有时间时，视为「全天 / 未定时间」。
- 完成 Todo **不清空**计划时段；它仍留在当天日程中，以已完成样式展示。
- 软删除的 Todo 从日程中消失。
- 改期即修改 `plannedDate` / `plannedStart` / `plannedEnd`，同时更新 `updatedAt`。

### 超期

- 已完成 Todo 永不超期。
- 有时间段：计划结束时刻已过 → 超期。
- 只有日期：该自然日已过（次日 00:00 起）→ 超期。
- 不做自动顺延；逾期项保留在原日期，用户可手动拖到今天。

## 2. 「日程」页签

主界面页签顺序：待办 / 日程 / 时间 / 日志。

- 日视图，默认今天；支持前后一天、「今天」跳转、日期选择。
- 顶部展示所在周（周一开头）的 7 天，标出每天未完成计划数，可点击跳转。
- 主体左侧为当天时间轴（默认 06:00–24:00，有更早/更晚安排时自动扩展），右侧为「待安排」列表。
- 时间轴按 15 分钟吸附；时间段重叠时左右分栏展示。
- 「全天 / 未定时间」的已安排待办单独展示在时间轴上方。
- 已完成但当天有计划的待办仍展示，使用置灰 / 删除线，不标红。
- 超期未完成项标红。

### 交互

- 从「待安排」拖到时间轴：设置当天日期 + 开始时间，默认时长 1 小时。
- 从「待安排」拖到「全天」区：只设置当天日期。
- 拖到周条的某一天：把计划日期改为该天（保留已有时间段）。
- 拖动已有时间块：修改开始时间，保持时长。
- 拖动时间块底边：修改结束时间，最小时长 15 分钟。
- 点击时间块：打开编辑弹层，可精确设置日期 / 开始 / 结束、清除安排、完成 / 取消完成。
- 「待安排」每项提供「安排」按钮，作为不依赖拖拽的精确输入入口。
- 所有改动保存后刷新当前周数据与「待安排」列表。

## 3. 待办列表集成

- 每条待办展示计划 chip（如 `今天 09:00–10:00`、`明天`）；超期标红。
- 展开编辑区增加计划设置入口，可设置 / 清除日期与时间段；保存时同时写回标题 / 详情与计划。
- 日程过滤由「日程」页签承担，待办列表不新增日期过滤。

## 4. Markdown 导出

- `todos.md` 每条待办在详情之后、`Created` 之前增加一行计划信息：
  - 有时间段：`计划：2026-10-31 09:00–10:00`
  - 仅日期：`计划：2026-10-31`
  - 未安排：不输出。
- 仍为单向导出，sqlite 是唯一事实源（ADR 0001）。

## 5. API / 存储

- 迁移 `0005` 为 `todos` 增加 `plannedDate` / `plannedStart` / `plannedEnd`，并建立 `plannedDate` 索引。
- 命令：
  - `todos_schedule(id, slot)` — 设置 / 清除计划时段。
  - `todos_scheduled(from, to)` — 取日期范围内的已安排待办（含已完成）。
  - `todos_unscheduled()` — 取未安排、未完成的待办。
- 计划的日期与时刻均为**本地墙钟**，不存 UTC 瞬时；跨时区/夏令时细节见 ADR 0005。

## 里程碑四明确不做

- 一个待办多段安排 / 每日重复日程
- 独立于计划时段的截止时间（deadline）字段
- 周 / 月日历网格、跨天时间段
- 番茄钟、按时完成率报表、外部日历同步
- 自动顺延逾期任务
- 日程的 markdown 独立导出文件（计划信息只随 `todos.md` 导出）
