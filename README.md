# H.E.R.B.I.E

H.E.R.B.I.E是用于待办跟踪、任务安排、时间记录、日志手账的个人助手。

## 里程碑一

搭建应用框架，实现基础功能：

- 基于 Tauri v2 + Rust + Vue 开发
- 主界面显示待办列表
- 数据存在本地sqlite
- 快捷键唤醒小窗口
  - 快速输入标题，按tab切换到输入详细内容
  - 回车提交
  - esc取消并关闭窗口
- 链接可以快速点击跳转，使用默认浏览器打开
- 可以添加label用于分类
  - 可以在详情中通过特殊标记（比如`#`）识别为label
- 记录创建时间，修改时间，完成时间
- 支持导出为markdown文件，方便git管理和AI决策

用户场景：快速添加待办

- 复制待办内容，比如链接或者文本
- 用快捷键唤醒小窗口，界面placeholder显示剪贴板内容
- 点击tab输入剪贴板内容，支持修改
- 点击enter创建待办，显示确认并收起小窗口

## 里程碑二

支持记录每天把时间花在哪

- 支持记录当前激活的程序/窗口，暂时支持Windows系统即可
- 支持手动导出markdown

## 里程碑三

日志/手账：记录会议纪要、每日思考，供后续归纳总结（详见 `docs/milestone-3-requirements.md`）：

- 统一为「日志条目」：归属某个自然日（天粒度），标题可选 + 正文必填
- 可补记过去日期、可改期；软删除
- 正文 `#tag` 与待办共享同一套标签体系
- 新「日志」页签，按日导航查看
- 手动导出 markdown（`journal/YYYY-MM-DD.md`），归纳总结由外部 AI 完成

## 里程碑四

支持任务拆解和规划功能：

- 输入中查找已有相似待办，特别是链接
  - 找到的话可以显示在右边，点击的话展开
- 可以设置任务的依赖关系（前置任务）
  - 可以显示树状依赖视图，类似科技树
  - 可以设置任务的前置/后置任务
- 支持拆解子任务
  - 主任务显示进度百分比（子任务完成数量占比）
- 定期备份本地数据库，周期可配

## 里程碑五

日程安排：

- 可以设置计划完成时间，或者计划时间段（开始和完成时间）
  - 支持设置到日期（或者周？），也支持设置到具体时间
  - 可以过滤本周/本日的待办
  - 超期标红
- 支持显示日历图，可以拖动修改开始和完成时间
  - 拖到周/日则设置为周/日
  - 拖动到时间条则设置开始时间（或者完成时间？），拖动前后可以修改开始和完成时间
- 考虑加入番茄时钟功能
- 报表功能，统计按时完成、延迟完成、最多延迟次数、完成率之类
- 支持同步外部日历日程
- 任务栏图标，显示今天剩余待办/总体剩余待办
